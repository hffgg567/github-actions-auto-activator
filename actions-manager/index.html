列出并手动启停工作流；自动识别 GitHub 因不活跃停用的工作流（disabled_inactivity）并一键激活。
需要 repo 权限（跨仓库时对所有目标仓库有效）
超过该天数才显示「一键启用」
填写仓库后，点击「加载工作流」
运行模式
  • 本地直连：双击打开本页，浏览器用你填的 Token 直接调 GitHub API。Token 只存本地。
  • 服务端模式：部署到 Vercel（本目录含 /api 反向代理）后，Token 存在服务端环境变量，页面无需填写，写操作也免跨域限制。
  • 批量「一键激活不活跃工作流」只处理状态为 disabled_inactivity 的工作流（GitHub 因 60 天未活动自动停用）。
  • 批量「全部禁用」只处理当前处于 active 的工作流。
  • 「停用 > N 天」以工作流 updated_at 近似最后变更时间。
  • 批量按钮会二次确认，请谨慎。
